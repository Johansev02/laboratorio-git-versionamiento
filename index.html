Laboratorio práctico de Git

Aprende control de versiones creando un proyecto real

Este proyecto permite practicar HTML, CSS, JavaScript, Git local y Git remoto de una manera sencilla, visual y práctica.

Haz clic en el botón para ver un mensaje dinámico.

¿Qué aprenderás en este laboratorio?

Git local

Aprenderás a inicializar un repositorio, agregar archivos y crear commits.

Git remoto

Conectarás tu proyecto local con un repositorio remoto en GitHub.

Proyecto web

Crearás una página funcional usando HTML, CSS y JavaScript.

Flujo básico de Git

El flujo recomendado es: git status -> git add . -> git commit -> git push.

Proyecto creado por un aprendiz para practicar Git local y Git remoto.
